# HockeyPlanner product recordings

Place the final optimized media here and enable each source in `src/config/productMedia.ts`.

```text
media/
  hero/hero.mp4, hero.webm, poster.jpg
  events/events.mp4, events.webm, poster.jpg
  attendance/attendance.mp4, attendance.webm, poster.jpg
  roster/roster.mp4, roster.webm, poster.jpg
  goalies/goalies.mp4, goalies.webm, poster.jpg
```

MP4/H.264 is required for Safari/iPhone. WebM is optional. Videos must be muted, contain no personal
data, and use stable demo content. Posters should match the first useful frame.
